# Marketing

This directory contains public-facing positioning, publishing, launch, media, podcast, website, and social-media materials for **The Seventh Kingdom**.

Marketing material is not a source of story canon. Every factual story claim, character description, quotation, promise, and reveal must be checked against [`../canon/`](../canon/) before publication.

## Files

- [`taglines.md`](taglines.md) — approved and exploratory positioning lines
- [`cover-copy.md`](cover-copy.md) — front-cover, spine, and promotional copy
- [`back-cover.md`](back-cover.md) — reader-facing book description
- [`publisher-query.md`](publisher-query.md) — publisher and agent query materials
- [`media-kit.md`](media-kit.md) — project and creator press resources
- [`website.md`](website.md) — site architecture and web copy
- [`launch-plan.md`](launch-plan.md) — release strategy and milestones
- [`podcast.md`](podcast.md) — podcast concepts and episode planning
- [`social-media.md`](social-media.md) — platform strategy and campaign assets

## Approval rule

Draft freely, label alternatives clearly, and publish nothing until Karl approves both the language and any canon-bearing claims.
