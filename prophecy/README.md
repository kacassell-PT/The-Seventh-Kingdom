# Prophecy

Workspace for tracking prophecy-related narrative claims, interpretations, reveal boundaries, and unresolved questions.

This folder must preserve the distinction among:

- biblical text;
- theological interpretation;
- fictional fulfillment or chronology;
- character belief;
- false or manipulated prophecy inside the story;
- Exploratory development proposals.

No fictional chronology becomes settled biblical interpretation by appearing here. Coordinate protected reveals with [`../showrunner/MYSTERY_TRACKER.md`](../showrunner/MYSTERY_TRACKER.md).
