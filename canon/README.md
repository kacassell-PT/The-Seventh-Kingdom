# Canon

This directory records approved continuity and canon decisions for **The Seventh Kingdom**.

## Core files

- [`CANON-INDEX.md`](CANON-INDEX.md) — registry of approved and proposed materials
- [`CHANGELOG.md`](CHANGELOG.md) — append-only record of canon decisions

## Status vocabulary

- **Canon** — explicitly approved by Karl
- **Provisional** — accepted for current development but still revisable
- **Exploratory** — proposed material under consideration
- **Deprecated** — formerly used but no longer active
- **Contradicted** — retained for provenance but incompatible with current canon

Nothing becomes Canon solely because it appears in this repository.
